# Multi-Domain Business Analytics Using SQL Server & Power BI

## About the Project

Multi-Domain Business Analytics is an end-to-end data analytics project developed using Microsoft SQL Server and Power BI. It focuses on analyzing business data across four major domains: Retail, Banking and Financial Services (BFSI), Healthcare, and Marketing.

The project aims to solve business-related analytical questions using SQL, evaluate key performance indicators (KPIs), identify trends and patterns, and transform data into meaningful insights through interactive Power BI dashboards.

By combining SQL-based data analysis with Power BI visualization, this project demonstrates how data can support business performance monitoring and data-driven decision-making.

## Project Objectives

- Analyze business data using Microsoft SQL Server.
- Solve business problems through SQL queries.
- Identify trends, patterns, and performance indicators.
- Analyze customer behaviour and business performance.
- Build interactive dashboards using Power BI.
- Present meaningful insights to support business decisions.

## Project Workflow

**1. Database Preparation**

Organizing business data in Microsoft SQL Server and preparing the database for analysis.

**2. SQL Analysis**

Writing and executing SQL queries to answer 15 business-focused analytical questions across four domains.

**3. Data Exploration**

Examining business performance, customer behaviour, trends, and key performance indicators.

**4. Dashboard Development**

Creating interactive Power BI dashboards with relevant charts, KPIs, filters, and visualizations.

**5. Business Insights**

Interpreting analytical results to identify patterns, evaluate performance, and support data-driven decision-making.

## Power BI Dashboard

The Power BI report provides an interactive view of the four business domains. Each domain contains dedicated report pages designed to explore its key business metrics and analytical questions.

Users can navigate between report pages, monitor KPIs, compare performance, and explore trends using interactive visualizations and filters.
